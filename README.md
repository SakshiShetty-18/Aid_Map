# TriageMap UI/UX Prototype

A frontend-only hackathon prototype built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No build step or backend is required.

## Features
- Simulated disaster incident queue and map-style visualization
- Explainable priority score panel
- Approve, edit and override incident actions
- Silent Zone Detector verification actions
- Local-session decision history, search and priority filters
- Responsive desktop/mobile layout

## Important
All incidents, scores and locations are simulated. This is a UI prototype, not connected to live emergency services. No rescue dispatch occurs.
